# Festival Packing Checklist

Pack one self-sufficient sunrise kit each night. EDC has no daily re-entry, so assume that once you enter, everything you need until morning must be with you or in a locker.

## Must bring to the festival every night

- [ ] Physical government photo ID or passport.
- [ ] EDC wristband.
- [ ] VIP ticket / VIP credential or lanyard if issued.
- [ ] One physical payment card.
- [ ] Phone with offline screenshots of shuttle, hotel, ticket, and emergency details.
- [ ] Empty hydration pack that follows EDC bag rules.
- [ ] Empty reusable water bottle as backup.
- [ ] Earplugs, plus backup pair.
- [ ] Power bank.
- [ ] Charging cable.
- [ ] Phone tether or wrist strap.
- [ ] Light night layer or pashmina.
- [ ] Sunglasses for sunrise / daytime entry.
- [ ] Lip balm.
- [ ] Eye drops.
- [ ] Cooling towel.
- [ ] Blister patches or moleskin.
- [ ] Gum or mints if sealed and allowed by current gate rules.
- [ ] Sealed naloxone if you carry it.

## Clothing plan

- [ ] 3 main festival outfits.
- [ ] 1 backup outfit.
- [ ] 5-6 pairs moisture-wicking socks.
- [ ] 5-6 pairs underwear.
- [ ] 2 broken-in sneaker pairs.
- [ ] 1 pair slides or recovery sandals.
- [ ] 1 hoodie, long sleeve, or pashmina for late-night wind and sunrise.
- [ ] 1 swimsuit and cover-up for resort downtime.

## Hotel / recovery kit

Keep these at the resort, not in your festival bag unless current EDC rules allow them:

- [ ] Electrolyte packets.
- [ ] Sunscreen.
- [ ] Aloe or after-sun lotion.
- [ ] Ibuprofen or preferred OTC pain reliever.
- [ ] Antacids.
- [ ] Sleep mask.
- [ ] Foam earplugs for daytime sleep.
- [ ] Compression socks.
- [ ] Laundry bag.
- [ ] Portable fan for the room.
- [ ] Rehydration drinks.

## Do not bring through EDC security

- Outside alcohol.
- Outside food or beverages.
- Aerosols.
- OTC medications unless the current official rules explicitly allow them.
- Opened makeup or liquids if they conflict with current gate rules.
- Large non-compliant bags.
- Anything with a barcode, ticket number, or ID photo that you would not want lost.
