# Dining Guide

Strategy: use included breakfast, sleep, make lunch the main meal, keep pre-festival dinner light.

## Included or package-related food/drink

| Meal / drink | Included? | Best use |
|---|---|---|
| ONO return breakfast | Yes | Eat after shuttle return before sleeping. |
| Welcome drink | Yes | Use at check-in. |
| Shuttle drinks | Yes | Enjoy, but still hydrate with water. |
| EDC VIP Beats & Breakfast | Yes for VIP, first come | Best around Kinetic Field sunrise sets. |
| ONO lunch package | Add-on unless your booking says otherwise | Useful if you want convenience. |
| ONO open-bar package | Ambiguous / likely add-on | Verify before assuming it is included. |

## Suggested food rhythm

### Thursday

- Arrival lunch or early dinner off-property.
- Keep dinner easy before the Kick-Off Party.
- Best options: Eataly, The Front Yard, Lotus of Siam, or Ferraro's if you want a nice meal.

### Friday

- Wake late.
- Main meal: ONO lunch add-on or Eataly.
- Light pre-festival snack.
- Breakfast after return.

### Saturday

- Breakfast after Friday return.
- Sleep.
- Main meal midday/afternoon.
- Keep pre-festival food simple.
- VIP breakfast if staying for Above & Beyond sunrise.

### Sunday

- Lowest-friction day.
- Main meal at resort/lunch add-on.
- Pack festival bag early.
- VIP breakfast before or after Armin sunrise if useful.
