# Sources and Privacy Notes

## Uploaded documents used

- United boarding pass PDF: flight route and flight timing only. Sensitive confirmation codes, ticket numbers, barcodes, and seat identifiers should not be committed.
- Ultimate EDC Las Vegas Hotel & Shuttle Package PDF: confirms One N Only package start date and package type. Sensitive ticket holder information should not be committed.
- Kick-Off Party Pass PDF: confirms Thursday May 14, 2026, 9:00 PM to 4:00 AM at Downtown Fremont Street. Sensitive ticket holder information should not be committed.

## Public sources to re-check before the trip

- Official EDC Las Vegas / Insomniac app: final lineup, stage assignments, set times, map, VIP amenities, shuttle rules, allowed/prohibited items.
- One N Only / Unity Travel communications: resort food and drink inclusions, pool party schedule, shuttle pickup times, wristband pickup, and check-in rules.
- Weather forecast: check Las Vegas forecast daily during the trip. This repo uses a planning forecast based on mid-May Las Vegas conditions; exact highs/lows can change.

## Privacy rule

Never upload PDFs, screenshots, barcodes, QR codes, confirmation codes, ticket numbers, passport/ID photos, or phone numbers to this repository.
