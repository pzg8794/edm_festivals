# One N Only Resort Plan

Use the resort package to reduce logistics, food decisions, and pre-festival friction.

## Confirmed or likely high-value inclusions

| Activity / service | Timing | Included? | How to use it |
|---|---|---|---|
| Check-in + welcome drink | Thursday after arrival | Yes | Easy arrival reset. |
| Kick-Off Party | Thu May 14, 9:00 PM-4:00 AM | Yes / pass held | Go, but do not overdo it before Friday. |
| Friday Opening Ceremony shuttle | Friday afternoon | Included for resort guests according to prior research | Use only if you want the full early EDC day. |
| Standard ONO shuttles | Festival evenings | Yes | Default departure around 7 PM unless going early. |
| Return shuttles | Late night / morning | Yes | Best return windows after sunrise sets. |
| Post-festival breakfast | After returning from EDC | Yes | Eat before sleep to avoid paying for breakfast. |
| Beauty bar | Onsite schedule TBD | Yes according to package description | Do hair/braids/gems before shuttle. |
| Tattoo parlor | Onsite schedule TBD | Included/advertised | Verify appointment process at check-in. |
| Lounge / games / contests | Daily schedule TBD | Yes | Use for low-energy daytime social time. |
| Silent disco afters | After festival return | Yes/likely | Only use if you still have energy. |
| Goat Yoga | Schedule TBD | Yes/advertised | Good recovery activity if not exhausted. |

## Resort checklist at check-in

Ask the front desk or One N Only host:

- [ ] Exact shuttle departure windows each day.
- [ ] Exact return shuttle pickup location and signage at Gate P.
- [ ] How to identify the One N Only tent at EDC pickup.
- [ ] Whether lunch is included in your specific booking or requires an add-on.
- [ ] Whether open bar is included in your specific booking or requires an add-on.
- [ ] Beauty bar hours and sign-up rules.
- [ ] Tattoo hours and sign-up rules.
- [ ] Pool hours.
- [ ] Daily resort activity calendar.
- [ ] Breakfast service window after EDC.
